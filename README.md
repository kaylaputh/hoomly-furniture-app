# Hoomly - Aplikasi Marketplace Furniture Mobile\n\nAplikasi marketplace furniture mobile yang dibangun dengan Flutter dan Firebase.\n\n## Fitur Utama\n\n- ✅ Authentication (Email/Password, Google Login, OTP)\n- ✅ Product Listing & Search\n- ✅ Wishlist\n- ✅ Shopping Cart\n- ✅ Checkout & Order Management\n- ✅ Order History\n- ✅ User Profile\n- ✅ Notifications\n\n## Stack Teknologi\n\n- **Frontend**: Flutter 3.0+\n- **State Management**: Riverpod\n- **Backend**: Firebase (Auth, Firestore, Storage)\n- **UI Framework**: Material 3\n\n## Setup\n\n1. Clone repository\n2. `flutter pub get`\n3. Setup Firebase credentials\n4. `flutter run`\n
